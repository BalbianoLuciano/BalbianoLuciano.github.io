# LinkedIn — qué cambiar, en orden

Comparado el 2026-10-06 contra el perfil de Bautista Priano Sobenko, que usa el
headline como lista de palabras clave (12 términos buscables; Luciano tenía cero
de desarrollo).

## 1. Headline (lo que más pesa en el buscador de recruiters)

```
AI Engineer & Full Stack Developer | OpenAI · Claude · Agentic RAG · MCP Agents | Laravel · Vue · React · TypeScript · Python · Docker | Team Leader | Remote | EU Citizen
```

169 de 220 caracteres. Sin emojis (decisión suya del 2026-10-06). Suma `AI Engineer`, `Laravel`, `Vue`, `React`,
`TypeScript`, `Python` y `Docker`. Saca "Spec Driven Development" (nadie lo
busca) y "LLM Integration" (redundante con OpenAI y Claude). Y corrige "Ai" por
"AI".

## 2. Puesto actual en Invisible Geeks — primer bullet

```
• Lead a development team of 2-3 developers: technical decisions, architecture, code review and mentoring, sprint management and stakeholder coordination
```

## 3. Dmeter — hoy es una línea de marketing sin una sola palabra buscable

```
Co-founder of a software studio with six products running in production across higher education, legal, retail, e-commerce and marketplaces.

• Built the internal MCP server (TypeScript, Model Context Protocol SDK) that centralises the studio's operations and is used daily by the whole team
• Built a RAG agent in Python: ChromaDB, multilingual embeddings, over-fetch with similarity threshold and re-ranking, LLM layer over Groq with automatic failover to OpenRouter
• Lead the technical decisions and architecture: multi-tenant isolation guaranteed at the database level, versioned business rules, and what has to be tested before anything ships
• One design rule across all of it: the system generates, the person decides

Tech: TypeScript · Python · Next.js · React · PostgreSQL · Drizzle · Cloudflare Workers · MCP · RAG · OpenAI API · Claude API
```

## 4. "Acerca de" — la línea de Tech Stack, al final

Agregar lo que falta: `Python`, `REST APIs`, `Git`, `CI/CD`, `Symfony`,
`Express`, `Scrum`. Hoy Python no aparece, y el CV de IA entero se apoya en eso.

## 5. "Acerca de" — primera línea

Cambiar "Ai native & Full Stack Developer" por **"AI Engineer & Full Stack
Developer"**, para que diga lo mismo que el headline. Y nombrar la empresa:
"Currently leading development at Invisible Geeks (Madrid)" en vez de "at a tech
company in Madrid" — el nombre es buscable.

## 6. La palabra "Senior"

No aparece en todo el perfil. Bautista abre con "Senior Software Engineer". Con
5 años y equipo a cargo corresponde, y muchos recruiters la usan como primer
corte. Entra sola si el puesto de Invisible Geeks pasa a **"Senior Full Stack
Developer | AI-Driven Team Leader"**.

## 7. Las dos inconsistencias

- **Ubicación**: LinkedIn dice Madrid, los CVs dicen "Argentina - Spain" y la
  regla del 2026-10-05 es no nombrar la ciudad. Tres versiones del mismo dato.
  Hay que elegir una y que las tres fuentes coincidan.
- **Título del puesto**: LinkedIn dice "AI-Driven Project Lead", los CVs y los
  mails dicen "Team Leader". Es el mismo trabajo con dos nombres.

## 8. Aptitudes (ya están los 100, el tope)

Las tres fijadas arriba son las que se ven primero. Deberían ser las del puesto
que persigue: **AI Engineering (o LLM)**, **Full-Stack Development** y
**Laravel** o **React**.
