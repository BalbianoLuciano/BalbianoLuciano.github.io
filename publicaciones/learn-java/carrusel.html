El problema

Un objeto
no se ve

Al que arranca con objetos no le falta la sintaxis: le falta el modelo mental. new no muestra nada, una referencia tampoco, y dos variables que apuntan al mismo objeto se ven idénticas a dos objetos distintos.

Lo que devuelve la consola es texto sobre algo que nadie vio nunca.

Si el estado del programa no se puede ver, el error se aprende de memoria en vez de entenderse.

Cómo está hecho

El estado
es real

La maqueta no interpreta el código: lo mira correr. El backend ejecuta el programa del alumno en un entorno aislado y lee el estado con JDI, la interfaz de depuración de la propia JVM. Lo que aparece en la escena son los objetos que existieron de verdad.
